# Bank Management System

A Java-based application to manage bank accounts, customers, deposits, withdrawals and transactions.

## Features
- Create New Account
- Deposit & Withdraw Money
- Check Account Balance
- View Transaction History
- Update Customer Details
- Delete Account
- Admin Login

## Tech Stack
- Language: Java
- Database: MySQL
- Concepts: OOP, JDBC, Collections
- Tools: Git, GitHub

## How It Works
1. Admin logs in
2. Creates customer account with details
3. Customer can deposit / withdraw money
4. System updates balance and saves transaction
5. User can check balance and transaction history
